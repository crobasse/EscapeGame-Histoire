# EscapeGame-Histoire

EscapeGame-Histoire est un site web d’énigmes où les utilisateurs doivent entrer deux codes pour obtenir un code final en retour. Ce projet s’inscrit dans le cadre d’un jeu d’évasion (escape game) à thématique historique, conçu pour être utilisé en classe, lors d’événements ou dans tout contexte ludique et éducatif.

## Fonctionnalités

- **Saisie sécurisée de deux codes** : Les participants doivent trouver et entrer deux codes distincts.
- **Génération d’un code final** : Si les deux codes sont corrects, le site fournit un code de sortie ou de progression.
- **Interface simple et intuitive** : Adaptée à un public scolaire ou familial.
- **Réutilisable et adaptable** : Les codes peuvent être personnalisés selon les besoins du jeu ou du scénario historique choisi.

## Utilisation

1. Accédez à la page principale du site.
2. Entrez les deux codes que vous avez trouvés lors de votre progression dans le jeu.
3. Cliquez sur le bouton de validation.
4. Si les deux codes sont corrects, un nouveau code vous sera donné pour continuer l’aventure ou terminer l’escape game.

## Installation

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/CleyhanRb/EscapeGame-Histoire.git
   ```
2. Installez les dépendances éventuelles (selon la stack utilisée, par exemple npm, yarn ou pip).
3. Lancez le serveur local :
   ```bash
   npm start
   ```
   ou selon les indications du projet.

## Personnalisation

- Vous pouvez modifier les codes attendus dans le fichier de configuration ou directement dans le code source.
- Adaptez les textes, indices et l’habillage graphique pour votre contexte historique.
